## 一、三个产品必须分清（v1 最大的坑：把三样东西当成一样）

Payoneer 旗下**三个完全不同的东西**，资格和用途天差地别：

| 产品 | 是什么 | 大陆个人可用？ | 我们什么时候用 |
|---|---|---|---|
| **Payoneer 收款链接**（Payment Link / 速盈收）| 发一个链接，客户点开付款（信用卡/ACH/PayPal/电汇）| ✅ **可用**（需KYC）| ⭐ **验证期就用这个** |
| **Payoneer Checkout 2.0** | 网站嵌入式结账（对标 Stripe Checkout）| ❌ **官方明确排除大陆实体** | 规模化阶段，且需香港实体 + 月流水 $20k |
| **Payoneer 收款账户**（Receiving Accounts）| 收平台打款（Upwork/Amazon 等）| ✅ 可用，但**不收自建站客户的钱** | 我们用不上（客户不在这些平台上）|

**v1 的错误就是把这三样混成了第一样。**

### 收款链接 vs Checkout 的关键差异

| 维度 | 收款链接（✅ 用这个）| Checkout（❌ 用不了）|
|---|---|---|
| 主体要求 | 个人 + KYC | **香港实体** |
| 流水门槛 | 无 | **月流水 > $20,000**|
| 技术接入 | **零代码**，后台点几下生成链接 | 需API 集成 |
| 订阅自动化 | ⚠️ **无自动续费**，靠人工催| ✅ 支持订阅 |
| 费率 | 信用卡约 3%（部分区域 2.5%）+ 提现费 | 2.9% + 通道费 |
| 单笔限额 | **$20–15,000** | 无此限制 |

## 二、验证期收款方案：Payoneer 收款链接

### 分工

```
用户访问 api.tiici.com/pricing          ← 我们的页面（自己开发）
        ↓ 点击「升级」
收到我们发的收款链接（Payoneer 生成的 URL）
        ↓ 用户点开，刷卡/转账
Payoneer 处理支付 → 资金进入 Payoneer 余额
        ↓ 我们人工确认到账
手动开通套餐                              ← MVP 阶段人工
```

### 必须接受的三个代价（这是真实约束，不是缺点掩饰）

| # | 代价 | 影响 | 应对 |
|---|---|---|---|
| 1 | **无自动续费** | 到期要人工发链接催收| 验证期只有 0–5 个用户，**人工完全够** |
| 2 | **到账非实时** | 信用卡约 1 小时，电汇 1–3 天 | 提前告知客户「付款后 1 小时内开通」 |
| 3 | **订阅状态靠人工维护** | 有客户忘了续、忘了降级 | 建一张表格：`客户 / 档位 / 到期日 / 状态` |

> **核心判断**：验证期的目标是**验证「有人愿意付 $9」**，不是**验证「订阅系统能自动运转」**。
> 花两周自研订阅状态机，而一个付费用户都没有，是本末倒置。

### 开通步骤（徐总本人操作，10–20 分钟）

| # | 步骤 | 说明 |
|---|---|---|
| 1 | 访问 `https://www.payoneer.com` →右上角 **注册** | 可切「简体中文」 |
| 2 | 选 **个人账户**（不是企业账户）| 企业账户要营业执照，我们没有 |
| 3 | 填邮箱 + 密码（≥8位，含大小写+数字+符号）| |
| 4 | 填个人信息：姓名、出生日期、国籍、居住地址 | ⚠️ **地址必须与后续证明文件完全一致** |
| 5 | 手机号收验证码 | |
| 6 | **上传身份证**（中国大陆用户用身份证）| 姓名与账户名一致 |
| 7 | **上传地址证明**：近 3 个月水电账单 / 银行对账单 / 信用卡账单 | ⚠️ **姓名 + 地址必须完全匹配**，错一个字母就驳回 |
| 8 | 绑定**本人名下**国内银行卡（工/建/农/中行均可）| ⚠️ 不能用他人账户 |
| 9 | 提交审核 | **1–3 个工作日** |

### 审核常见驳回原因（照着避）

| # | 原因 | 怎么避 |
|---|---|---|
| 1 | 地址证明上的姓名/地址与填写的不一致 | 上传前逐字核对，缩写也算不一致 |
| 2 | 身份证照片模糊/过期/反光 | 关闭闪光灯，四角完整 |
| 3 | 银行账户不是本人名下 | 用自己的卡 |
| 4 | 短时间内换 IP 登录（含用 VPS 登录）| ⚠️ **注意：我们的服务器在东京，如果用服务器 IP 登录 Payoneer 会触发风控** |
| 5 | 提交后频繁修改资料 | 一次提交到位 |

> ⚠️ **第4 条特别提醒**：我们刚买了东京服务器。
> **不要用 `167.179.112.40` 登录 Payoneer 后台**，那个 IP 在境外且是数据中心 IP，
> 极易触发反洗钱风控导致账户冻结。**只用你家里/办公室的网络登录。**

## 四、三个必须消除的误解

### 误解 1：「Lemon Squeezy 被 Stripe 收购 = 我们用 Stripe」

**不相关。** Stripe 收购 Lemon Squeezy 是它自己的商业动作（2024-07）。
我们既不用 Lemon Squeezy，当前也不用 Stripe。

### 误解 2：「订阅界面是支付平台的」

**订阅界面完全是我们自己的。** 分工：


**平台只负责"收钱"这一段**，产品界面、套餐逻辑、开通判断都是我们的。

### 误解 3：「我们给 Stripe 提供运营服务」

**方向反了。** 我们是**付费使用** Stripe 的客户，不是它的运营方。

## 七、香港主体的两条税务风险（必须知道）

### 风险 1：CFC 规则 —— 离岸免税不是白拿的

香港 2025-01-01 生效的**受控外国公司（CFC）规则**：

> 若香港离岸公司的**最终控制方为内地税收居民**，且该公司在港**实际税负低于内地对应税负的 50%**、**无实质性运营活动**，
> 相关利润**需并入内地居民企业的应纳税所得额，缴纳内地企业所得税**。

**应对**：保留真实业务与决策留痕（合同、邮件、会议记录能证明决策发生在实质经营地），**或咨询专业税务师**。

### 风险 2：零申报 ≠ 免税

| 误区 | 真相 |
|---|---|
| 「所有香港公司都可零申报」 | ❌ 只有**无经营、无流水、无资产负债**才能零申报 |
| 「离岸就不必报税」 | ❌ **每年必须报税**，无运营的可申请"不活动公司"申报 |
| 「注册资本越高越好」 | ❌ 股权转让需缴 **0.2% 印花税**，越高成本越高 |

⚠️ **2026 年香港税务局上线大数据交叉比对系统**（对比银行流水 + 海关进出口 + 跨境支付数据），
**虚假零申报处以应缴税款 3 倍罚款**，情节严重追究刑责。

### 年度合规节奏（别忘）

| 事项 | 频率 | 逾期后果 |
|---|---|---|
| 商业登记证 BR 续期 | 每年 | — |
| 利得税申报 | 每年（首次为成立后 **18 个月**）| 罚款 1,200–10,000 港币 |
| 周年申报表 NAR1 | 每年 | **超 6 个月罚 HK$3,480，董事可能列入失信名单限制出入境** |
| 审计报告 | **无论盈亏均须提交** | 无运营也要出无运营审计报告 |
| SCR 重要控制人登记册 | 存放注册地址备查 | 最高罚 HK$25,000，**每日加 HK$700** |

## 八、Form 5472 的坑（为何不选美国 LLC）

⚠️ **Form 5472 是"美国 LLC 看起来最便宜"这个判断里最大的暗坑。**
它的本质不是税，而是**反避税信息申报**——不缴税不等于不用报。

| # | 坑 | 说明 |
|---|---|---|
| 1 | **触发门槛低到反直觉** | 不看收入，看「是否发生过与外方股东之间的应报告交易」。**汇一笔启动资金、报销一次注册代理费、无息借款，全都要报**。**没有任何金额门槛，1 美元和 100 万美元规则相同** |
| 2 | **罚款与欠税完全脱钩** | 一分钱税没欠，照样罚。**$25,000/份/年**，一个 LLC 对 3 个关联方 = $75,000 起 |
| 3 | **「实质不完整」= 「没交」** | 表交了但漏几笔交易、或用错年份的表格版本，同样按未申报处理，**罚金一分不减** |
| 4 | **无诉讼时效，越拖越贵** | IRC 6501(c)(8)：未申报的信息申报表**诉讼时效永久不启动**。IRS 发CP-215 通知后 90 天宽限期，逾期**每 30 天再加 $25,000，按每个关联方分别计，法定无上限** |
| 5 | **不能电子申报** | 需填 pro forma Form 1120（顶部手写 "Foreign-owned U.S. DE"，正文金额栏全空）作为封面，**必须寄到Ogden 专用地址或传真**，只认传真回执 |
| 6 | **减免基本不成立** | 「首次申报免罚」（FTA）**不适用**于 6038A；「我不知道有这条法规」一律不接受。实务上多数案例选择**直接补交并缴罚款** |
| 7 | **不能自动化掉** | 这笔「每年必做、必须手工完成、漏了巨罚」的申报，**完全无法靠软件或 API 免除** |

### ⚠️ 一个必须澄清的流传错误

很多人把 Form 5472 和 FinCEN 的 **BOI（受益所有人信息申报）**混为一谈：

| 项目 | 状态（2026-10）|
|---|---|
| **BOI（CTA）** | FinCEN 于 **2026-08-11** 发布最终规则（**2026-08-14 生效**），**美国境内设立的公司全部豁免**，无需申报，也无需更新已提交的 FinCEN ID |
| **Form 5472（IRS）** | **完全不受影响，继续执行，罚款不变** |

> ⚠️ 如果某篇文章说「美国 LLC 不用做任何申报了」，那是把 BOI 豁免错套到 5472 上。
> **新设的美国 LLC 仍完全落在 5472 义务范围内。**

## 九、三条税务底线

1. **个人年度境外收入超 12 万人民币需自行申报缴税** —— 平台不代办
2. **Payoneer / Airwallex / Stripe 都只解决"收钱"，VAT 等税务要自己扛**
3. 外汇局年度结售汇便利化额度已上调至 **$100,000**；各平台收汇需按外汇管理规定申报
   → **建议第 3 周咨询专业会计**（申报义务不复杂，但踩错很麻烦）
