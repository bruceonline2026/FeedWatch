### 三个高发模式（都属「静默失效」家族）

| 模式 | 表现 | 为什么普通测试抓不住 |
|---|---|---|
| **静默停调度** | API 返回 200，监控点实际已停 | 只读返回值，不查实际行为 |
| **只声明不强制** | 声明 A，实际执行 B | 只校验 schema，不测行为 |
| **只覆盖部分方法** | GET 有校验，PATCH/DELETE 没有 | 测试名声称覆盖，实际只测一条 |

> 07-12 就已记录：**「这类缺陷不会被任何『跑一下看看』的验证发现」**。
> 07-16 的 4 个新缺陷里有 3 个是同一家族 —— **教训没有自动生效，
> 是靠回退法才抓到的**。

## ⚠️ 五、必须知道的三个约束

### 1. 收款顺序不能颠倒

```
Payoneer 账户验证通过 → 才能生成收款链接 → 才能收款
        ↓
   现在卡在这里（1-3 工作日）
```

**这期间能做的**：收集意向、免费层试用、提交注册表让产品被看见。

### 2. 重启服务 = 所有 Key 失效

**不只是监控点，Key 本身也会失效**（只存哈希，重启后 seed 不回来）。

D7 修好前，**重启前必须通知所有客户**。

### 3. 本机装工具要走代理

Apple Silicon · 无 Homebrew · `/usr/local/bin` 不可写 ·
**GitHub release 附件直连会 502** → 走 `ghfast.top`，
**但必须核对官方 SHA256**。
