## ⚠️ 五、必须知道的三个约束

### 1. 收款顺序不能颠倒

```
Payoneer 账户验证通过 → 才能生成收款链接 → 才能收款
        ↓
   现在卡在这里（1-3 工作日）
```

**这期间能做的**：收集意向、免费层试用、提交注册表让产品被看见。

### 2. 重启服务 = 所有 Key 失效

**不只是监控点，Key 本身也会失效**（只存哈希，重启后 seed 不回来）。

D7 修好前，**重启前必须通知所有客户**。

### 3. 本机装工具要走代理

Apple Silicon · 无 Homebrew · `/usr/local/bin` 不可写 ·
**GitHub release 附件直连会 502** → 走 `ghfast.top`，
**但必须核对官方 SHA256**。
