# 更换收款链接（Payoneer 单次链接的日常操作）

**最后更新**：2026-10-17

---

## 一句话背景

Payoneer 的收款链接**每条只能用一次**。官方原文：

> Each link is **single-use**: it's tied to one buyer and one transaction.
> **Once it's paid, the link can't be reused.**

所以「把链接直接写进落地页」是错的 —— 收第一笔钱链接就作废，
之后任何客户点付费按钮都会看到：

```
That payment link was already paid
```

> ⚠️ **这比没有付款入口更糟** —— 客户会怀疑你是个不靠谱的卖家。

---

## 现在怎么解决的

```
落地页按钮  →  https://api.tiici.com/pay   ← 永不改变
                    ↓ 302 跳转
服务器 /opt/feedwatch/pay-link.json 里的当前有效链接
                    ↓
              Payoneer 付款页
```

**所以落地页、README、推文里印的 URL 永远不用改。**

链接用完 → 只改服务器上**一个文件**。

---

## 你要做的（换新链接，约 1 分钟）

### 第 1 步：在 Payoneer 后台建新链接

```
收款 → 创建收款链接
```

| 字段 | 填什么 |
|---|---|
| **链接名称** | `FeedWatch Pro — $29/12 months` ← ⚠️ 别写 `$29/month`，实际是 12 个月一次付 |
| 金额 | 固定 `29.00` USD（最低 $20）|
| 到期日期 | `2027-10-16`（一年，别用默认的 3 个月）|
| 手续费承担方 | **Recipient**（你承担 3%）→ 客户实付正好 $29 |
| 描述 | 用最保守字符，别带 `https://` 的双斜杠 |

### 第 2 步：复制新链接

形如 `https://link.payoneer.com/Token?t=XXXXXXXX&src=pl`

### 第 3 步：把它交给我

**直接贴给我就行**，我改服务器配置 + 验证，约 1 分钟。

> 也可以自己改，但要走下面的 SSH 命令 ——
> 找错文件或格式错误会导致按钮变成 503 提示页。

---

## 自己改的话（SSH 命令）

```bash
ssh feedwatch-vultr
sudo nano /opt/feedwatch/pay-link.json
```

内容形如：

```json
{
  "url": "https://link.payoneer.com/Token?t=你的新链接&src=pl",
  "note": "Payoneer single-use link. After each payment, replace this file.",
  "updated": "2026-10-17"
}
```

**改完立即生效，不需要重启服务**（每次请求都重读文件）。

### 验证

```bash
curl -s -o /dev/null -D - https://api.tiici.com/pay | grep -i location
```

应该看到 `location: https://link.payoneer.com/Token?t=你的新链接...`

## 万一忘了换会怎样

| 情况 | 表现 |
|---|---|
| 链接已用完 | 客户看到 Payoneer 的 "already paid" 页 |
| **配置文件被删/格式错** | 客户看到 **503 提示页**（友好文案 + 你的邮箱），不会白屏 |

⚠️ **死链与活链的 HTTP 响应完全相同**（都是 302），
所以**系统无法自动检测链接是否作废**，也没有自动告警。

> 💡 想彻底解决，去 Payoneer 问客服能否开通
> **可复用链接（reusable link）** —— 官方说该功能
> "subject to eligibility"（需符合资格），个人账户不一定能过。

## 日常检查清单

| 什么时候 | 检查什么 |
|---|---|
| **每次收到付款后** | 立刻换新链接（否则下一个客户看到死链）|
| 每天 | 看一眼 Payoneer 后台有没有新交易 |
| 提现前 | 确认 $29 已变成可提现余额 |
