### ❓「后台看不到 Checkout 菜单」—— 这是正常的，不是账户出问题

Payoneer 后台左侧导航只有 7 项：**主页 · 收款 · 付款 · 卡 · 费用支出预算 · 提款与转换 · 管理**。
**没有 Checkout 入口，是因为 Checkout 2.0 明确不面向中国大陆个人/实体**（官方条款原文见 §一），
所以系统**根本不会给大陆账户显示这个菜单** —— 你没找错，也不用申请。

对比一下这三个容易混的东西：

| 你想收的钱 | 在后台哪里 | 大陆个人可用 |
|---|---|---|
| 直接发个链接让客户付款 | **收款 → 请求付款**（Request A Payment）| ✅ **就是这条** |
| 让客户直接在你的网站里刷卡结账（嵌入式）| **Checkout** 菜单 | ❌ 菜单不显示，需香港实体 + 月流水 $20k |
| 收电商平台/客户电汇打款 | **收款 → 收款账户**（美元电汇账户 WPS）| ✅ 可用，但客户得主动电汇 |

### 👉 第 5 步怎么走

**路径**：左侧 **「收款」→ 请求付款**（英文界面 Get Paid by Clients → Payment Links）

官方 FAQ 原文：
> "Log in to your Payoneer account, go to **Get Paid by Clients**, and select **Payment Links**.
> Enter your client's details, set the amount and currency, and generate your link."

⚠️ 中文界面叫**「请求付款」**（不是「付款链接」），功能是同一个东西。
它会生成一条付款 URL，你发给客户 → 客户点开 → 用信用卡/储蓄卡/PayPal/电汇付钱 → 资金进你的 Payoneer 余额。

| 项 | 建议填法 |
|---|---|
| 金额 | 首个链接建议 **$1**（仅验证链路能跑通，不真收款）|
| 币种 | **USD**（客户多为境外，美元最通用）|
| 客户姓名/邮箱 | 可先用自己的（**仅自测**）；给真实客户时再填对方邮箱，Payoneer 会把账单发到对方邮箱 |
| 描述/备注 | `FeedWatch Subscription` |

**零代码，不需要任何 API 集成。** 生成后把URL 直接发给客户即可。
（同一菜单里还有「向多个付款方提出批量付款请求」，上传 CSV 一次发多封 —— 5 个用户阶段用不上，先不用管。）

> ⚠️ 若首页Balances 区块显示 "Looks like we have a problem" —— **不影响生成链接**，
> 先点 Refresh 重试；仍不行再走左侧「管理」菜单排查。

### 第 6 步：首笔到账测试

| 项 | 说明 |
|---|---|
| 测试金额 | **$1** 即可 |
| 到账时效 | 信用卡约**1 小时**；其他方式 3 天内 |
| 到账后 | 余额出现在首页 Balances → 手动开通对应套餐 |
| ⚠️ 实测坑 | 单笔限额 **$20–15,000**；链接生成与发送**免费**，信用卡收款约 3% 手续费 |

## ⛔ 先看这一条：我们用的不是 Payoneer Checkout

Payoneer 有三个不同产品，**资格天差地别**。开错会白忙3 天还开不了。

| 产品 | 大陆个人可用？ | 我们用吗 |
|---|---|---|
| **Payoneer 收款链接**（Payment Link / 速盈收）| ✅ **可用**（需KYC）| ⭐ **就这个** |
| Payoneer **Checkout 2.0** | ❌ **官方明确排除中国大陆实体**（需香港实体 + 月流水 $20,000）| ❌ |
| Payoneer 收款账户（Receiving Accounts）| ✅ 但只收Upwork/Amazon 等平台打款 | ❌ 我们的客户不在那些平台上 |

**官方原文**（`https://www.payoneer.com/checkout/`，2026-10-15 核实）：

> "Checkout service is provided by Stripe Inc. and/or its affiliates exclusively to
> US and Hong Kong entities. **This service is not intended for and does not include
> individuals or entities located within Mainland China.**"

> ⚠️ 本手册**不要**去申请 Checkout。

## 一、开通前准备（先备齐，别边填边找）

| # | 材料 | 注意事项 |
|---|---|---|
| 1 | **身份证**（中国大陆用户）| 正反面，四角完整，无反光。**姓名必须与账户名一致** |
| 2 | **地址证明**：近3 个月的水电账单 / 银行对账单 / 信用卡账单 | ⚠️ **姓名 + 地址必须与填写的一致，错一个字母就驳回** |
| 3 | **本人名下国内银行卡** | 工/建/农/中行均可。**不能用他人账户** |
| 4 | 常用邮箱 | 能长期收信 |
| 5 | 手机号 | 收验证码 |
| 6 | 稳定的登录网络 | ⚠️ **见下方警告** |

### ⚠️ 千万别用我们刚买的东京服务器登录 Payoneer

服务器 IP `167.179.112.40` 是**境外数据中心 IP**。用它登录 Payoneer 后台，
极易触发反洗钱风控导致**账户被冻结**。

✅ **只用你家里/办公室的固定网络登录。**

（这是 Payoneer 风控的常见触发项之一：IP 频繁切换、数据中心 IP、单日大额异动。）

## 二、注册步骤（10–20 分钟）

| # | 步骤 | 说明 |
|---|---|---|
| 1 | 打开 `https://www.payoneer.com` | 右上角语言可切**简体中文** |
| 2 | 点 **注册 / Register** | |
| 3 | 选 **个人账户** | ⚠️ **不是企业账户** —— 企业账户要营业执照，我们没有 |
| 4 | 填邮箱 + 密码 | 密码 ≥8 位，含大小写字母 + 数字 + 符号 |
| 5 | 填基本信息 | 姓名、出生日期、国籍、居住地址 |
| 6 | 手机收验证码 | |
| 7 | **上传身份证** | |
| 8 | **上传地址证明** | ⚠️ 姓名地址必须完全匹配 |
| 9 | **绑定本人银行卡** | |
| 10 | 提交审核 | **1–3 个工作日**，结果邮件通知 |

> ⚠️ **地址必须前后一致**：第 5 步填的地址、第 8 步证明文件上的地址、
> 第 9 步银行账户上的地址，**三处必须对得上**。这是最高频驳回原因。

## 三、审核驳回的六个原因（照着避）

| # | 原因 | 怎么避 |
|---|---|---|
| 1 | 地址证明的姓名/地址与填写不一致 | 上传前逐字核对，**缩写也算不一致** |
| 2 | 身份证模糊 / 过期 / 反光 | 关闪光灯，四角完整，光线均匀 |
| 3 | 银行账户不是本人名下 | 用自己的卡 |
| 4 | **IP 频繁切换 / 用境外 VPS 登录** | ⚠️ **只用固定家庭网络** |
| 5 | 单日交易金额集中异常 | 分散交易，别一次性大额 |
| 6 | 提交后频繁改资料 | 一次提交到位 |

**超过 3 个工作日没通过**：查垃圾邮件 → 登录后台看「待办事项」→ 官网帮助中心提工单。

## 四、开通后：生成收款链接（收第一笔钱）

### 路径

```
Payoneer 后台 → Get Paid by Clients（从客户收款）→ Payment Links（收款链接）
```

### 操作

| # | 步骤 | 说明 |
|---|---|---|
| 1 | 进Payment Links | |
| 2 | 填金额 + 币种 | USD $9 |
| 3 | 选客户信息 | 首次要新建联系人：姓名、邮箱、国家 |

## 五、完整收款流程（我们要做的四件事）

```
① 客户付了钱
      ↓
② 我们收到 Payoneer 邮件/后台通知
      ↓
③ 【人工】确认到账 → 记录到账时间与金额
      ↓
④ 【人工】开通套餐（发 API Key / 放宽限流）→ 发确认邮件
```

### ⚠️ 验证期必须人工做的四件事

| # | 事项 | 为什么不能自动化 |
|---|---|---|
| 1 | 确认到账 | Payoneer 收款链接**没有支付成功 webhook** |
| 2 | 维护套餐状态 | 没有 Billing API，不知道谁续费了 |
| 3 | 到期降级 | 同上，得靠表格 |
| 4 | 催续费 | 链接到期即失效，不会自动续 |

> **核心认知**：验证期的目标是**验证「有人愿意付 $9」**，
> 不是**验证「订阅系统能自动运转」**。
> 0–5 个用户，人工完全够。**不要为这 5 个人自研订阅状态机。**

## 六、费用（2026-10 采集）

| 项 | 费率 |
|---|---|
| 注册 | 免费 |
| 年费 | **$29.95**（年收款超 $6,000 豁免）|
| 生成并发送收款链接 | **免费** |
| 信用卡收款 | 约 **3%**（部分区域可优惠至 2.5%）|
| 提现到国内银行 | **约 1.2%–2%**（部分渠道 0.5% + 最低 $15）|
| 单笔收款限额 | **$20–15,000** |

**验证期成本估算**（5 用户 × $9/月 = $45/月）：

| 项 | 金额 |
|---|---|
| 收款手续费（$45 × 3%）| $1.35 |
| 提现费（$45 × 1.2%）| $0.54 |
| 年费分摊（$29.95 ÷ 12 × 8/52）| ≈$0.38 |
| **合计** | **≈$2.3 / 月** |

> 对照服务器 $5/月。**收款成本比服务器还低**，验证期完全不是问题。

> ⚠️ **费率以官网 `payoneer.com` 的 fees page 为准。** 上表为2026-10 第三方采集值。

## 七、三条合规提醒（不能忽略）

### 1. 个人年度境外收入超 12 万人民币需自行申报缴税

平台**不代办**。验证期收入很低，但**收入累计要记清楚**，
超过门槛就咨询会计。

### 2. 资金必须收付到本人名下账户

不得代收代付。违反《外汇管理条例》第 48 条，可能被罚款或列入关注名单。

### 3. 提现被拒的三个常见原因

| 原因 | 规避 |
|---|---|
| 姓名拼音与银行卡不符（误差率 > 8%）| **统一拼音格式**，以银行开户信息为准 |
| IP 频繁切换（尤其用 VPS）| 用固定网络 |
| 交易金额集中 | **单次提现控制在 $2,000 以内** |

## 八、什么时候要换方案？

| 触发条件 | 换什么 | 为什么 |
|---|---|---|
| 月流水接近 **$20,000** | 开始考虑 **香港实体 + Checkout 2.0** | Checkout 的官方门槛 |
| 付费用户 > 20个，手工维护不过来 | 自研订阅系统 + 可用的支付 API | 人工成本超过自动化成本 |
| 确定要接 **Stripe** | 注册香港公司，开 Stripe HK | Stripe 不支持大陆主体 |
| 需要**平台分账** | 必须换（Checkout 和 Stripe 都有 Connect）| Payoneer 无分账能力 |

> **判断原则**：Payoneer 收款链接可以**一直用下去**，收入规模不大时不必换。
> **不需要为了「看起来专业」而升级到 Checkout。**

## 九、常见问题

| 问题 | 答案 |
|---|---|
| 客户需要注册 Payoneer 吗？ | **不需要**。点链接直接刷卡 |
| 链接会过期吗？ | 单次链接默认有有效期；订阅场景要勾「可重复使用」 |
| 能自动续费吗？ | ❌ 不能。到期需我们再发链接 |
| 能开发票吗？ | 平台只能出平台抬头发票，**无法自主开发票抬头** |
| 支持支付宝/微信付款吗？ | ❌ 不支持。客户需用信用卡或银行转账 |
| 收款链接能嵌在自己的网站里吗？ | ⚠️ 是跳转，**不是嵌入式结账**（嵌入式是 Checkout 2.0 才行，而我们用不了）|
| 客户信用卡账单显示谁？ | 显示 **Payoneer**，不是我们的名字。**要在 FAQ 里写明**，避免被当诈骗 |
