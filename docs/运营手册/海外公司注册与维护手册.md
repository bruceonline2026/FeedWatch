# 海外公司注册与维护手册

**用途**：从"要不要办"判断 → 香港公司注册 → 银行开户 → 后续合规维护
**适用**：FeedWatch MCP 需要接 Stripe 时
**最后更新**：2026-10-15

---

## 零、先判断：现在真的需要办吗？

**这一章是本文档最重要的一章。** 很多教程把"买海外服务器"和"注册境外公司"绑一起讲，**这是错的**。

### 主体需求判断表

| 事项 | 需要境外主体？ | 原因 |
|---|---|---|
| **买 Vultr 服务器** | ❌ **不需要** | Vultr 官方支持**支付宝/微信**，大陆个人可直接充值 |
| **Linux 部署** | ❌ 不需要 | 纯技术动作 |
| **Payoneer 收款链接** | ❌ 不需要 | **个人可开通**，1–3 天 |
| **Payoneer Checkout 2.0** | ✅ **必须（香港实体）** | ⚠️ 官方条款：Checkout **仅面向美国与中国香港实体，不面向中国大陆境内的个人或实体**，且需**月网店流水 > USD $20,000** |
| **Airwallex 收款** | ⚠️ 企业版需要 | 但有个人通道可先用 |
| **接 Stripe 收款** | ✅ **必须** | **Stripe 明确不支持中国大陆主体** |

> ⛔ **2026-10-15 纠错**：原表写「Payoneer Checkout 个人可开通」**是错的**，
> 与 Payoneer 官方条款直接冲突。验证期改用**收款链接（Payment Link）**。
> 来源：`https://www.payoneer.com/checkout/`（核实于 2026-10-15）
> 详见 `docs/决策/决策记录-收款与主体.md` v2

### 成本对比（为什么不要提前办）

| 项 | 月成本 | 说明 |
|---|---|---|
| Vultr 服务器 | **$5** | 验证期配置（实测）|
| 收款手续费 + 提现 | ≈$2 | 5 用户 × $9，约 3% + 1.2% |
| **香港公司维护** | **≈$83** | 秘书+地址+报税+年检，约 $1,000/年 |

**主体成本 ≈ 服务器成本的 16 倍，而验证期 8 周总收入（$45）还没这个数。**

### ⭐ 结论

> **验证期（0–5 付费用户）不要办主体。**
> 等验证通过、真要接 Stripe 或 Checkout 2.0 时再办 —— 这时成本才摊得薄，且你已经知道业务真实规模。

**当前进度**：服务器 ✅ **已部署** · Payoneer 收款链接 ⏳ **待开通** · 主体 ⏸️ **暂缓**

## 一、三个主体的选择

### 对比

| 项 | **香港公司** | 美国 LLC | 英国 Ltd |
|---|---|---|---|
| Stripe 账户 | Stripe HK | Stripe US | Stripe UK |
| **费率** | 3.4% + HK$2.35 | **2.9% + $0.30**（最低）| 视政策 |
| 董事要求 | **大陆居民可任唯一股东兼董事** | 无限制 | 需本地董事？|
| 本地董事 | **不需要** | 不需要 | 通常需要 |
| 税务编号 | 无（利得税报税制）| **需 EIN**（海外申请慢）| 需 UTR |
| 年度维护 | 报税+年检+**审计报告** | 州年报+**IRS Form 5472** | 年报+报税 |
| **踩坑代价** | 中 | **高**（Form 5472 漏报罚款可达 $25,000）| 中 |
| 办理周期 | **1–3 工作日出证书** | 数周（EIN 慢）| 数周 |
| 办理成本 | 规费 HK$1,970 +秘书地址 HK$8,000–12,000/年 | 州费 $300/年+代理 $150–300/年 | 更高 |
| **适合** | ⭐ **亚太客户、全球交付** | 北美市场且有专业会计 | 欧洲市场 |

### ⭐ 推荐：先走香港

**理由**：

1. **不需要赴港**，全程线上，1–3 工作日出证书
2. 公司账户可用**董事护照**过 KYC（个人账户才要香港身份证）
3. **允许 100% 外资持股**
4. 无外汇管制，资金进出自由
5. **合规负担比美国 LLC 可控** —— Form 5472 的坑不值得踩

⚠️ **若主要客户在北美且月入稳定 $5万+，再评估美国 LLC。**

## 二、香港公司注册（可照做）

### Step 1：确认硬性条件

| 项 | 要求 | 我们 |
|---|---|---|
| 股东/董事年龄 | 年满 18 周岁 | ✅ |
| 国籍 | **无限制** | ✅ |
| 人数 | 至少 1 名自然人董事（可与股东为同一人）| ✅ 一人即可 |
| 法定秘书 | **必须委任持牌 TCSCP 秘书公司** | 需代办机构提供 |
| 注册地址 | **香港本地商用地址，不可邮政信箱** | 需代办机构提供 |
| 赴港要求 | **不需要本人赴港** | ✅ |

### Step 2：材料清单

- [ ] 大陆居民身份证正反面扫描件（清晰、与原件一致、无涂改）
- [ ] 有效**港澳通行证或护照**扫描件（含个人信息页、近 3 个月签注页、本人签名页，**签名需与申请文件一致**）
- [ ] 拟用公司名**准备 3 个备选**
- [ ] 近 3 个月地址证明（水电煤账单/银行对账单/运营商账单，**需显示全名与完整地址**；电子账单需带电子章）
- [ ] 注册资本认缴声明（**建议 1 万港币**，无最低要求、无需实缴）
- [ ] 注册地址证明（房产证 或 租赁合同 + 业主同意书）
- [ ] 法定秘书委任文件

⚠️ **公司名禁用词**：银行、信托、保险、基金会、大学；「中国」「国家」需特别审批。
⚠️ **英文名必须以 `Limited` 结尾，中文名以「有限公司」结尾。**

### Step 3：注册流程

| 步骤 | 内容 | 周期 |
|---|---|---|
| 1 | **名称查册**（`cr.gov.hk` 免费系统，实时查重） | 即时 |
| 2 | **名称预留** | **14 天保护期** |
| 3 | 材料签署（电子签）| 1–2 天 |
| 4 | 通过「注册易」线上提交 | — |
| 5 | 注册处审核 | **线上 1–2 工作日**；纸质 5–7 工作日 |
| 6 | 领取 **CI**（公司注册证书）+ **BR**（商业登记证）| 电子与纸质同等法律效力 |
| 7 | **注册后 1 个月内**向税务局提交**开业申报表** | — |

### Step 4：费用

| 项目 | 金额 | 备注 |
|---|---|---|
| 公司注册费 | **HK$1,720** | 固定规费 |
| 商业登记证 BR | **HK$250**（1 年）| 部分报价含 3 年期 HK$2,250 |
| 法定秘书（首年）| HK$3,000–6,000 | **服务类，差异最大** |
| 注册地址（首年）| HK$1,200–2,400 | 同上 |
| **政府规费合计** | **约 HK$1,970** | |
| **持牌秘书代办全套** | **HK$8,000–12,000 / 年** | 第二年常见涨到 HK$3,000+/年 |

⚠️ **警惕「零元注册」陷阱**：有些中介免费注册，后续通过代账、年审、银行开户加收高额服务费。

**签约前必须确认三件事**：
1. 报价是否含**首年法定秘书 + 注册地址**
2. **第二年续费价**是多少
3. 对方是否为**持牌秘书公司**（可在香港公司注册处官网公示名单查询）

## 三、注册后的配套事项

### 银行开户

⚠️ **目前仍需面签**（部分机构支持授权书代办）。

| 银行 | 说明 |
|---|---|
| 中银香港 / 汇丰 / 渣打 | 主流，但对内地客户尽职调查趋严 |
| Airwallex 空中云汇 | **对已有香港实体友好**，多数 **48 小时**审核通过；董事不到场可用授权书代办 |

**开户通常需要**：
- 公司注册证书 CI + 商业登记证 BR
- 公司章程、董事身份证明
- **业务说明**（合同样本、流水凭证）
- 地址证明

⚠️ **⚠️ 业务描述要写清楚，避免频繁大额异动** —— Airwallex 的账户冻结投诉占一星差评六成以上。

## 四、⚠️ 两条必须知道的税务风险

### 风险 1：CFC 规则 —— 离岸免税不是白拿的

香港 **2025-01-01** 生效的**受控外国公司（CFC）规则**：

> 若香港离岸公司的**最终控制方为内地税收居民**，且该公司在港**实际税负低于内地对应税负的 50%**、**无实质性运营活动**，
> 相关利润**需并入内地居民企业的应纳税所得额，缴纳内地企业所得税**。

**通俗说**：你是内地税收居民、用香港公司收 Stripe 订阅、但公司没有实质运营（无办公、无雇员、决策都在内地做）——**利润理论上要回内地补税**。

**应对**：
- 保留真实业务与决策留痕（合同、邮件、会议记录能证明决策发生在实质经营地）
- **或咨询专业税务师** —— 这笔钱不该自己猜

### 风险 2：零申报 ≠ 免税

| 误区 | 真相 |
|---|---|
| 「所有香港公司都可零申报」 | ❌ 只有**无经营、无流水、无资产负债**才能零申报 |
| 「离岸就不必报税」 | ❌ **每年必须报税**，无运营的可申请"不活动公司"申报 |
| 「注册资本越高越好」 | ❌ 股权转让需缴 **0.2% 印花税**，越高成本越高 |

⚠️ **2026 年香港税务局上线大数据交叉比对系统**，将报税数据与**银行流水、海关进出口、跨境支付平台数据**比对，
**虚假零申报处以应缴税款 3 倍罚款**，情节严重追究刑责。

## 五、年度合规日历

**注册后每年要做的事，务必设提醒。**

| 事项 | 频率 | 逾期后果 |
|---|---|---|
| **商业登记证 BR 续期** | **每年** | 罚款 |
| **利得税申报** | **每年**（新公司首次为成立后 **18 个月**）| 罚款 1,200–10,000 港币 |
| **周年申报表 NAR1** | **每年** | **逾期 3–6 个月罚 HK$2,610；超 6 个月罚 HK$3,480，董事可能被列入香港失信名单、限制出入境** |
| **审计报告** | **无论盈亏均须提交**（无运营也要出无运营审计报告）| 无法完成报税 |
| **SCR 重要控制人登记册** | 存放注册地址，随时备查 | **最高罚 HK$25,000，每日另加 HK$700** |
| **离岸豁免申请** | 符合条件时 | 核查周期 8–18 个月 |

### 报税流程

```
课税年度结束（3-31）→ 税务局寄出利得税表（1 个月内）
    ↓
3 个月内提交申报（新公司首次可延至成立后 18 个月）
    ↓
准备全套凭证：银行流水、业务合同、收支凭证、运营单据
    ↓
委托香港执业会计师做账 + 出具审计报告
    ↓
提交利得税表 + 审计报告
    ↓
若符合离岸豁免条件 → 同步提交豁免申请（附业务发生地证明）
```

**利得税税率**：两级制，首 **200 万港币 8.25%**，超过部分 **16.5%**（现行至 2027-12-31）。
**非源自香港的利润无需在香港缴税**（但受 CFC 规则约束，见风险 1）。

## 六、三条税务底线

1. **个人年度境外收入超 12 万人民币需自行申报缴税** —— 平台不代办
2. **Payoneer / Airwallex / Stripe 都只解决"收钱"，VAT 等税务要自己扛**
3. 外汇局年度结售汇便利化额度已上调至 **$100,000**；各平台收汇需按外汇管理规定申报
   → **建议找专业会计咨询一次**（申报义务不复杂，但踩错很麻烦）
